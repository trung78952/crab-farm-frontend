# Crab Farm Frontend

Vue 2 dashboard for Crab Farm AI.

## Local development

```bash
cd crab-farm-frontend
npm install
npm run serve
```

Default URL: http://localhost:8080

Create `.env.local` if needed:

```bash
VUE_APP_API_BASE_URL=http://localhost:8000
```

Login with the backend seed admin:

- username: `admin`
- password: `admin123`
